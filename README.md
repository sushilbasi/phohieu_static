# Phở Hiếu website (static)

Plain HTML / CSS / JS — no server needed. Open `index.html` in a browser, or upload
the whole folder to any static host (Netlify, GitHub Pages, Cloudflare Pages, etc.).

- `menu.js`   – edit dishes and prices here (format explained at the top of the file)
- `script.js` – builds the menu tabs from `menu.js`
- `index.html`, `style.css`, `logo.webp` – page layout, styling and logo
